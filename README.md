# GMS — Landing Page

Product landing page for **GMS (Global School Management System)**, part of the Bytencia portfolio.

- **Live page:** https://gms-landing.netlify.app/
- **Live product (ERP login):** https://gms-react.vercel.app/login
- **Product code:** https://github.com/shubhamdiyos/gms

Static single-page site — `index.html`, `styles.css`, `script.js`, `favicon.svg`. No build step; deploy the files as-is (currently hosted on Netlify).

**Content rule:** everything on this page must stay limited to the verified GMS case-study facts (five role-based experiences — Admin, Teacher, Student, Parent, Staff; smart dashboards; automation replacing registers, spreadsheets and WhatsApp chaos). No invented numbers, school counts, institution names, testimonials or savings claims.
